# 📚 My Machines Documentation

Welcome to the comprehensive documentation hub for **My Machines** — an open-source initiative empowering makers, hobbyists, and innovators with accessible, DIY digital fabrication machines.

## 🎯 About This Project

This repository contains the complete documentation for all **My Machines** open-source projects, including:

- **3D Printers** - User-friendly and highly customizable models (My Mini, My CoreXY, My Delta, My Giga1m3, My Cloner)
- **CNC Routers** - Precision machines for cutting and carving (My PCB Mill, My Router CNC, My Router XL)
- **Laser Machines** - Versatile cutting and engraving systems (My CO2 Laser, My Diode Laser, My Fiber Laser)
- **Educational Content** - Learn the basics of digital fabrication
- **Open Source Components** - FreeCAD files, electronics guides, and more

## 🚀 Features

- ✨ **Well-Organized Documentation** - Easy navigation by machine type and project
- 🌍 **Multi-language Ready** - Global community support
- 📱 **Responsive Design** - Works on desktop and mobile devices
- 🔍 **Full-Text Search** - Find information instantly
- 🎨 **Dark/Light Mode** - Eye-friendly viewing options
- 💾 **Open Source** - All documentation is version-controlled on GitHub
