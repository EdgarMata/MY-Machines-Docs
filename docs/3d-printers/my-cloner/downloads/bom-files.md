# Bill of Materials

Download the complete **My-Cloner Rev A Bill of Materials**.

The BOM contains the mechanical, frame, fastener, electronic, hotend and 3D printed components required to build the printer.

!!! info "Authoritative BOM"
    **My-Cloner BOM V2** is the authoritative Bill of Materials for the My-Cloner Rev A.

    The web documentation provides a human-readable reference, while these downloadable files contain the complete revision-controlled BOM.

## BOM Contents

The downloadable BOM includes the following sections:

| Section | Contents |
|---|---|
| **Mechanical** | Motion components, rods, bearings, belts, pulleys and build plate |
| **Frame** | Aluminium profiles and custom structural components |
| **Fasteners** | Screws, nuts, washers and T-nuts |
| **Electronics** | Power, control, motors, sensors, cooling and Klipper host hardware |
| **Hotend** | V6-compatible hotend components |
| **3D Printed Parts** | Complete list of printed parts required for the Rev A build |

## XLSX or CSV?

Use the **XLSX workbook** when you want:

- The complete structured engineering BOM
- Separate component sections
- An editable spreadsheet
- Purchase and sourcing information
- Notes and specifications

Use the **CSV file** when you want:

- A simple machine-readable BOM
- Easy importing into other software
- Data processing or scripting
- A single consolidated component list

## Sourcing Components

Purchase links included in the BOM are provided for convenience and may include affiliate links.

The component **specification is more important than the vendor link**.

If a listed product becomes unavailable, an equivalent component may be used when it meets the required specifications.

!!! warning "Check the Hardware Revision"
    These files apply to the **My-Cloner Rev A**.

    Do not mix BOM files from older prototypes or previous hardware revisions with the current Rev A build.
