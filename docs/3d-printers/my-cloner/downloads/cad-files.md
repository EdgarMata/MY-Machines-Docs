# CAD Files

This page provides the currently available CAD and manufacturing files for the **My-Cloner Rev A**.

At this stage, the free downloadable CAD package contains the **DXF manufacturing files** used for the frame and related components.

The complete editable 3D project is available separately in SketchUp format through the MyMachines store..

## DXF Files

The 2D manufacturing files used for the My-Cloner frame and related components are available in **DXF format**.

These files can be used for processes such as:

- Laser cutting
- CNC cutting
- Waterjet cutting
- Manufacturing reference
- Dimensional inspection

!!! info "Open File Format"
    DXF files can be opened and edited using free tools such as
    <a href="https://www.qcad.org/" target="_blank" rel="noopener noreferrer">QCAD</a>.

    You are not required to use proprietary CAD software to access these files.

## Why Is the Complete CAD Project Paid?

MyMachines aims to make the knowledge required to understand, build and maintain these machines openly accessible.

At the same time, developing a machine requires real resources:

- Design time
- Prototypes
- Components
- Testing
- Documentation
- Hosting and infrastructure

The optional complete CAD package provides a way for users who find the project useful to help support that work.

!!! tip "You Can Still Build the Machine"
    Purchasing the complete CAD project is **not required to build the My-Cloner**.

    The BOM, documentation, STL files, DXF manufacturing files, firmware information and other essential build resources remain available separately.

## Future CAD Formats

The long-term goal is to provide the My-Cloner project in more open and interoperable CAD formats.

Planned formats include:

- STEP
- FreeCAD-compatible project files

When these formats become available, this page will be updated.

For STEP files in the future, a free and open-source CAD application such as
<a href="https://www.freecad.org/" target="_blank" rel="noopener noreferrer">FreeCAD</a>
can be used to open and edit the models.
