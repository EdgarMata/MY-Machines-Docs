# 3D Printable Parts (STL)

Here you can download all the necessary STL files to print the parts for your MY-Cloner 3D Printer. The files are separated by color for easier printing organization.

We recommend printing the parts with the specified colors to match the project's aesthetics, but feel free to use any color you like.
