# Firmware Configuration

The firmware configuration for the **My-Cloner Rev A** is still under development.

The planned software architecture is based on:

- **Klipper**
- **Raspberry Pi Zero 2 W**
- **MKS Robin Nano V3**
- **Mainsail**

The final configuration will include the required Klipper files, including the printer configuration used by the My-Cloner Rev A.

!!! warning "Not Yet Available"
    The official My-Cloner Rev A Klipper configuration is **not yet available for download**.

    This includes the final `printer.cfg` and the complete Raspberry Pi / Klipper setup required for the printer.

## Planned Downloads

This page will later provide:

- My-Cloner Rev A `printer.cfg`
- Klipper configuration files
- Raspberry Pi setup instructions
- Mainsail configuration guidance
- MCU firmware information for the MKS Robin Nano V3
- Required macros and machine-specific settings

## Important

Do not use configuration files from older My-Cloner prototypes, MK3S-based projects or unrelated printers.

The final configuration must match the actual My-Cloner Rev A hardware, including:

- Mainboard
- Motor configuration
- Probe
- Thermistors
- Heaters
- Fans
- Endstop or sensor configuration
- Build volume
- Motion limits
