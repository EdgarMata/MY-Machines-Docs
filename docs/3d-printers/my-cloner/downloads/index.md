## Open Tools, Open Files

You do not need proprietary or paid software to access the My-Cloner project files.

Free and open-source tools can be used for the main file formats provided in this project:

- **XLSX / CSV:** <a href="https://www.libreoffice.org/" target="_blank" rel="noopener noreferrer">LibreOffice</a> or <a href="https://www.onlyoffice.com/" target="_blank" rel="noopener noreferrer">ONLYOFFICE</a>
- **STEP and other 3D CAD formats:** <a href="https://www.freecad.org/" target="_blank" rel="noopener noreferrer">FreeCAD</a>
- **DXF and 2D CAD files:** <a href="https://www.qcad.org/" target="_blank" rel="noopener noreferrer">QCAD</a>
- **ZIP / 7z archives:** <a href="https://www.7-zip.org/" target="_blank" rel="noopener noreferrer">7-Zip</a>

!!! tip "Use the Tools You Prefer"
    These applications are suggestions, not requirements.

    The goal is to keep the project files accessible through open and widely supported formats, allowing you to choose the tools that best fit your workflow.

## Hardware Revision

The files in this section apply to:

**My-Cloner — Hardware Rev A**

Before downloading or manufacturing parts, verify that the file belongs to the hardware revision you are building.

Future revisions may introduce changes to:

- Mechanical parts
- Printed parts
- Electronics
- Wiring
- Firmware
- Slicer profiles

## Recommended Workflow

For a new build:

1. Download and review the [Bill of Materials](bom-files.md).
2. Obtain the required mechanical and electronic components.
3. Download and print the required [STL Files](stl-files.md).
4. Use the [CAD Files](cad-files.md) when manufacturing custom components.
5. Follow the [Assembly Guide](../assembly/01_introduction.md).
6. Complete the electrical installation using the [Wiring & Electronics](../wiring/index.md) documentation.
7. Install the [Firmware Configuration](firmware-configuration.md).
8. Configure the recommended [Slicer Profiles](slicer-profiles.md).

!!! warning "Do Not Mix Revisions"
    Files from different hardware revisions may look similar while having important dimensional, electrical or configuration differences.

    Always use a consistent set of files for the same My-Cloner hardware revision.
