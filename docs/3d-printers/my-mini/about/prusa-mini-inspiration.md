# Prusa Mini Inspiration

The MY-Mini-3D-Printer is heavily inspired by the Prusa Mini, a compact and reliable 3D printer designed by Prusa Research. The Prusa Mini is known for its:

- Print area: 180 x 180 x 180 mm
- Removable magnetic spring steel sheet with PEI
- Color LCD display and intuitive UI
- Silent stepper drivers (TMC2209)
- 32-bit mainboard
- Automatic mesh bed leveling (SuperPINDA)
- Open-source firmware and hardware

The MY-Mini adapts many of these features, offering a similar print volume, removable PEI bed, silent drivers, and a modular, easy-to-assemble design. The main differences are the use of Makerbase electronics and a custom mechanical structure, but the user experience and print quality are inspired by the Prusa Mini philosophy: reliability, ease of use, and open documentation.

For more information about the Prusa Mini, visit the official page: https://www.prusa3d.com/product/original-prusa-mini/
