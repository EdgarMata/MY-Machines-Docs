# Specifications

- Print volume: 180 x 180 x 180 mm

- Display: 4.3" color touchscreen (MKS H43)

- Stepper drivers: TMC2209 (silent)
- Heated bed: Magnetic, removable PEI sheet
- Power supply: 12V 330W
- Supported materials: PLA, PETG, ABS, ASA, TPU, Nylon, PC
- Connectivity: USB, SD card
