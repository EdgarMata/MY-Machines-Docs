# Slicer

This section presents software recommendations, profiles, and ideal parameters to achieve the best print quality on the MY-Mini-3D-Printer, based on Prusa Mini experience.

## Compatible Software
- **PrusaSlicer** (recommended)
- **Ultimaker Cura**
- **Simplify3D**

## Base Profile (Prusa Mini)
- Use the Prusa Mini profile as a starting point.
- Adjust the print volume to 180x180x180 mm.
- Enable "mesh bed leveling" and "silent mode" if available.

## Suggested Parameters
- Layer height: 0.2 mm (default), can vary between 0.05 and 0.25 mm
- Speed: up to 60 mm/s
- Nozzle temperature: 200–250°C (PLA, PETG, ABS, ASA, TPU, Nylon, PC)
- Bed temperature: up to 100°C
- Retraction: 0.8–1.2 mm at 35 mm/s
- Fan: 100% for PLA, 50% for PETG/ABS

## Prusa Mini Tips
- Use "first layer slow" for better adhesion.
- Enable "elephant foot compensation" to avoid base expansion.
- Test different infill patterns (gyroid, grid, cubic).
