# Troubleshooting

This section helps you solve common problems with the MY-Mini-3D-Printer, based on community experience and Prusa Mini tips.

## Adhesion Issues
- **Symptom:** First layer does not stick to the bed.
- **Solutions:**
  - Clean the PEI sheet with isopropyl alcohol.
  - Adjust the Z-offset.
  - Make sure the bed is leveled (mesh bed leveling).

## Extrusion Failures
- **Symptom:** The extruder does not pull the filament or makes a "clicking" sound.
- **Solutions:**
  - Check if the nozzle is clean.
  - Adjust the extruder tension.
  - Make sure the filament is not jammed.

## Layer Shifting
- **Symptom:** Layers are misaligned.
- **Solutions:**
  - Check belt tension.
  - Tighten pulleys and motor screws.
  - Lubricate the axes.

## Temperature Errors
- **Symptom:** Hotend or bed does not heat or shows an error.
- **Solutions:**
  - Check thermistor and heater connections.
  - Replace faulty components.

## Firmware Issues
- **Symptom:** Printer does not start or shows error messages.
- **Solutions:**
  - Reflash the firmware.
  - Check driver and sensor configuration.

## Prusa Mini Tips
- Check forums and user groups for quick solutions.
- Use the firmware "Selftest" whenever possible.

> If the problem persists, share details in the My Machines community for collaborative support.
