# Heat Bed BOM

This document lists all the parts required to assemble the heat bed for the MY-CoreXY-3D-Printer.

## Non-Printed Parts

This section details the non-printed components for the heat bed.

| Part Number | Description | Quantity | Notes |
|---|---|---|---|
| HB-0001 | Heated Bed 220x220mm | 1 | 24V PCB heat bed. |
| HB-0002 | Borosilicate Glass 220x220mm | 1 | Or other build surface like PEI. |
| HB-0003 | Bed Spring | 4 | For leveling the bed. |
| HB-0004 | Thumbwheel | 4 | For adjusting the bed level. |

## Printed Parts

This section lists all the printed parts for the heat bed. All files are provided in the correct orientation for printing.
