# Enclosure BOM

This document lists all the parts required to build the enclosure for the MY-CoreXY-3D-Printer.

## Non-Printed Parts

This section details the non-printed components for the enclosure.

| Part Number | Description | Quantity | Notes |
|---|---|---|---|
| EN-0001 | Acrylic Panel 3mm | 4 | Clear or tinted acrylic panels for the sides. |
| EN-0002 | Door Hinge | 2 | For the front door. |
| EN-0003 | Door Handle | 1 | A simple handle for the door. |
| EN-0004 | Magnetic Catch | 2 | To keep the door closed. |

## Printed Parts

This section lists all the printed parts for the enclosure. All files are provided in the correct orientation for printing.

### Printing Instructions
The following table shows the recommended print settings.

| Perimeters | Layer Height | Infill | Material | Supports |

| 4 | 0.2mm - 0.3mm | 25% | PETG, ASA or ABS | As needed |
