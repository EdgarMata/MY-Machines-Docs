# Z-Motion BOM

This document lists all the parts required to assemble the Z-axis motion system for the MY-CoreXY-3D-Printer.

## Non-Printed Parts

This section details the non-printed components for the Z-axis.

| Part Number | Description         | Quantity | Notes                          |
|--------------|---------------------|----------|--------------------------------|
| ZM-0001      | Stepper Motor       | 1        | NEMA17 motor.                 |
| ZM-0002      | Lead Screw 300mm    | 1        | T8 lead screw with 2mm pitch. |
| ZM-0003      | Anti-backlash Nut   | 1        | To prevent backlash on the Z-axis. |
| ZM-0004      | Flexible Coupler    | 1        | 5mm to 8mm coupler.           |
| ZM-0005      | Linear Rod 8mm 350mm| 2        | Hardened steel rods.          |
| ZM-0006      | Linear Bearing LM8UU | 4        | For smooth vertical movement.  |

## Printed Parts

This section lists all the printed parts for the Z-axis. All files are provided in the correct orientation for printing.
