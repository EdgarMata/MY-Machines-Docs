# Frame BOM

This document lists all the parts required to build the frame for the MY-CoreXY-3D-Printer.

## Non-Printed Parts

This section details the non-printed components for the frame.

| Part Number | Description | Quantity | Notes |
|---|---|---|---|
| FR-0001 | 2020 Aluminum Extrusion 300mm | 4 | For the X-axis and bed frame. |
| FR-0002 | 2020 Aluminum Extrusion 350mm | 4 | For the Y-axis. |
| FR-0003 | 2020 Aluminum Extrusion 400mm | 4 | For the Z-axis (vertical frame). |
| FR-0004 | Corner Bracket | 12 | To assemble the frame corners. |
