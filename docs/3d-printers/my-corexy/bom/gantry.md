# Gantry BOM

This document lists all the parts required to assemble the gantry for the MY-CoreXY-3D-Printer.

## Non-Printed Parts

This section details the non-printed components for the gantry.

| Part Number | Description | Quantity | Notes |
|---|---|---|---|
| GA-0001 | Linear Rail MGN9 300mm | 2 | For the X-axis. |
| GA-0002 | Linear Rail Carriage MGN9H | 2 | For the X-axis linear rails. |
| GA-0003 | GT2 Timing Belt | 5m | 6mm width. |
| GA-0004 | GT2 Pulley 20T | 2 | For the stepper motors. |
| GA-0005 | Idler Pulley | 2 | Smooth or toothed idlers. |
| GA-0006 | Stepper Motor | 2 | NEMA17 motors for the A and B axes. |

## Printed Parts

This section lists all the printed parts for the gantry. All files are provided in the correct orientation for printing.

The following table shows the recommended print settings.

| 4 | 0.2mm - 0.3mm | 25% | PETG, ASA or ABS | As needed |
