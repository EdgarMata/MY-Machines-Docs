# Required Tools 

Having the right tools on hand will not only make the build process easier and faster, but also safer and more precise. Below is a list of essential and recommended tools.

!!! tip "A Worthy Investment"
    A set of good-quality hex drivers (Allen keys) is perhaps the most important investment you can make for this build. Poor-quality drivers can strip the heads of screws, causing enormous headaches later on.

### Essential Tools

* **Hex Drivers (Allen Keys)**: Sizes 1.5mm, 2.0mm, 2.5mm, 3.0mm. Ball-end drivers are highly recommended.
* **Soldering Iron**: Essential for installing heat-set inserts and for the wiring section.
* **Digital Multimeter**: For checking continuity, voltages, and identifying wires. A crucial safety tool.
* **Flush Cutters**: For cutting zip ties and filament cleanly.
* **Hobby Knife (X-Acto)**: For cleaning up burrs or imperfections on printed parts.
* **Digital Calipers**: For verifying dimensions and ensuring everything is assembled correctly.
* **Wire Strippers**: Indispensable for the wiring section.
* **Crimping Tool**: If you plan to use JST or Dupont connectors for a professional finish.
* **Tweezers**: Very useful for handling small parts and routing belts.
