# How to Create a Spotify Code Product

Adding a scannable Spotify Code to your products—like keychains, acrylic lamps, or wooden plaques—is a fantastic way to personalize your work. Follow this simple guide to generate and prepare your code for the **Neon**.

---

## 1. Get the Spotify Link
Open your Spotify app, find the song, album, or playlist you want to use, and **Copy the Link** (Share > Copy Link).

## 2. Generate the Vector Code
To get a high-quality engraving, you need a vector file of the code:
1.  Go to [SpotifyCodes.com](https://www.spotifycodes.com).
2.  Paste your link into the bar and click **Get Spotify Code**.
3.  **Important:** Set the "Format" to **SVG**. This ensures the lines stay sharp when you resize them in **Neon Studio**.
4.  Keep the background white and the code black for the easiest setup.
5.  Download the file to your computer.

---

## 3. Importing to Neon Studio

Now, let's prepare the file for engraving:

1.  **Import:** Go to **File > Import...** and select your SVG file.
2.  **Scale:** Ensure the "Manual Scale" option is checked so the code remains at a scannable size (don't make it too tiny!).
3.  **Edit:** If the SVG includes a background box you don't want, select it and delete it. You only need the bars and the Spotify logo.
4.  **Position:** Align the code on your product (e.g., a keychain base).
5.  **Settings:** Move the code to an **Engraving Layer**.

## 4. Engraving Parameters

For a code to be scannable, it needs good contrast:
* **For Wood/MDF:** Use **Medium Resolution** with enough power to create a dark brown mark.
* **For Clear Acrylic:** Engrave on the back (Reverse) in **High Resolution** and then paint the bars with a dark color for better scanning.
* **For Metal:** Use a thermal marking additive to ensure the bars are jet black.

---

!!! success "Testing is Key"
    Before finishing your product, always test the engraved code with your phone's Spotify camera (Search > Camera Icon). If it doesn't scan immediately, you may need to increase the engraving depth or contrast.
