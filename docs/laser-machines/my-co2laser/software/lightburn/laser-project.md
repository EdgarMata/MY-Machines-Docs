# WiFi QR Code Coaster Project

Learn how to design, engrave, and cut a functional QR code WiFi coaster in LightBurn. This project allows guests to access your network simply by scanning the coaster with their phone.

## Prerequisites
* **Material**: 3mm Plywood.
* **Software**: LightBurn.
* **Tools**: QR Code Generator (built into LightBurn).

## Step-by-Step Guide

### 1. Create the Text
* Select the **Text Tool (A)** from the left toolbar [00:00:51].
* Type "Wi-Fi" or your preferred text.
* Ensure the font is legible. For this project, **Dosis Extra Bold** was used [00:03:34].

### 2. Generate the QR Code
* Go to the top menu: **Tools > Create QR Code** [00:03:54].
* Click and drag in the workspace to draw the code.
* In the properties window, select the **Wi-Fi tab**.
* Enter your **Network Name (SSID)** and **Password** (case sensitive!) [00:04:12].
* Set the size between **40mm and 60mm** [00:05:00].

### 3. Alignment and Grouping
* Select both the text and the QR code.
* Use **Align Vertical Center** to align them [00:05:26].
* Click **Group** to treat them as a single object [00:05:39].

### 4. Create the Coaster Outline
* Use the **Ellipse Tool** while holding **Shift** to create a perfect circle [00:06:21].
* Align the circle to the center of your design using the **Target icon** [00:06:46].
* Use the **Offset Tool** to create an outer cutting path (e.g., 4mm outward) [00:07:51].

### 5. Layer Settings
* **Engrave Layer (Black/Blue)**: Set to **Fill** mode for text and QR code [00:06:03].
* **Cut Layer (Red)**: Set to **Line** mode for the final cutout [00:08:20].
* Always check the **Preview window** before starting to verify the scanning and cutting order [00:02:15].

### 6. Laser Setup
* Focus your laser using the appropriate spacer [00:09:41].
* Use the **Frame** button to ensure the project fits your material [00:10:37].
* Wear safety glasses and ensure proper ventilation [00:12:29].
