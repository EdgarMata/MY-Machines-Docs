# Apply Path to Text

The **Apply Path to Text** tool allows you to place text so that it follows the specific contour or shape of another object in your workspace.

## How to Use Apply Path to Text
1. **Create your objects**: You need a single block of text and a single shape (this can be a straight line, a circle, or a complex curve).
2. **Select both**: Select the text and the shape at the same time.
3. **Apply the tool**: Go to the **Tools** menu and select **Apply Path to Text**.
4. **Automatic adjustment**: The text will immediately move to the shape and wrap itself along its contour.

## Adjusting the Position
Once the text is attached to the path, you can fine-tune its position using the **Text Options** toolbar:
* **Align X**: Moves the text along the length of the path (left, right, or center).
* **Align Y**: Adjusts whether the text sits on top of, inside, or outside the path.
* **Dynamic Updates**: If you edit the shape of the path after the text is attached, the text will automatically move and adjust to the new contour.

## Pro Tip: Tool Layers
If you used a shape as a guide but you **do not** want that shape to be engraved or cut by the laser:
* Select the shape.
* Assign it to a **Tool Layer** (the orange T1 or T2 entries in the color palette). Tool layers are used for reference and are never sent to the laser.
